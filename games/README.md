# 🏀 Brain Warmups — Big Numbers Game

A fun, self-contained game to *feel* the difference between **1 million, 1 billion, and 1 trillion**.

## How to play

No build step, no internet, no login. Just open the file in any browser:

```
games/big-numbers-game.html
```

(Double-click it, or drag it into a browser tab.)

## What's inside

Five mini-games / scenarios:

1. **🤯 The Big Idea** — the zeros side by side, plus a "if a million were 1 basketball" bar chart that makes the 1,000× jumps obvious.
2. **⏱️ Time Warp** — count one number per second and see how far back in time a million / billion / trillion seconds lands (a million ≈ 11.5 days, a billion ≈ 32 years, a trillion ≈ 31,700 years / the Ice Age).
3. **💸 Spending Spree** — a slider for how fast you splurge; watch how long it takes to drain each prize, plus a stack-of-cash height comparison.
4. **🔬 Scale-O-Vision** — each dot = 1 million; visually see why a trillion needs *1,000 whole screens*.
5. **🧠 Quiz Challenge** — 10 scored questions with streak bonuses, a final rank, and keyboard shortcuts (`1`–`4`).
